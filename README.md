# PT Pragata Makmur Persada — Website Resmi & CMS

Website profil perusahaan modern untuk **PT Pragata Makmur Persada**, kontraktor infrastruktur telekomunikasi terkemuka di Indonesia (Instalasi Fiber Optik, Menara & BTS, Survey & Design Jaringan, dan Managed Services).

Dibangun menggunakan stack teknologi mutakhir **Next.js 16 (App Router & Turbopack)**, **Tailwind CSS**, dan dilengkapi dengan panel **Content Management System (CMS)** internal untuk pembaruan konten dan foto secara real-time.

---

## 🚀 Fitur Utama

- **Desain Modern & Responsif**: Tampilan profesional dengan identitas brand resmi (Navy & Cyan), tipografi tajam, dan optimasi menyeluruh untuk desktop, tablet, maupun mobile.
- **Simbol Layanan Modern**: Ikonografi berteknologi tinggi untuk 4 lini pekerjaan utama dengan efek interaktif.
- **Pop-up Detail Layanan & Berita**: Jendela pop-up modal interaktif untuk membaca detail teknis layanan maupun artikel berita lengkap.
- **Running Marquee Partner**: Barisan logo mitra operator telekomunikasi & ISP dengan animasi geser otomatis (*continuous auto-slide ticker*) dan pause saat hover.
- **Panel Admin CMS (`/admin` atau `/root`)**:
  - Dilindungi otentikasi kata sandi.
  - Pengeditan banner hero, caption, dan foto utama.
  - Manajemen berita & publikasi proyek (tambah, edit, upload foto, hapus).
  - Manajemen portofolio proyek.
  - Manajemen partner & klien (tambah logo, auto-slide).
  - Manajemen teks 4 lini layanan, statistik, dan info kontak.
  - Unggah foto langsung dari perangkat (*direct file upload*).
- **SEO & Performa**: Skor performa tinggi, sitemap XML otomatis, metadata OpenGraph, dan Schema.org JSON-LD.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Image Processing**: Sharp & Next.js Image Optimization
- **Bahasa**: TypeScript

---

## 💻 Memulai Proyek

Jalankan server pengembangan lokal:

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

### Akses Panel Admin:
- URL: `http://localhost:3000/admin` (atau `/root`)
- Kata Sandi Default: `pragata2026`

---

## 📦 Build Produksi

Untuk membuat build produksi:

```bash
npm run build
npm run start
```
